## 1. Tujuan

Aplikasi tracking gizi harian untuk melakukan proses diet berkala dengan memasukan semua asupan gizi yang dimakan pada hari tersebut:

1. **Logging Makanan** —  Terdapat 4 jenis sesi makan yaitu Breakfast, Lunch, Snack dan Dinner.
2. **Detail Logging Makanan** — Ketika masuk ke detail Logging Makanan, User memasukan nilai gizi yaitu Calories, Total Fat (g), Total Carbohydrates (g), Protein (g) dan Time dan dapat diubah.
3. **Daily Calories** — Setiap makanan yang telah di input di hari tersebut, maka calories akan otomatis bertambah sesuai dengan yang user masukan pada setiap detailnya, untuk Target Daily Calories nya bisa di customize by User Input.
4. **Daily Carbs, Fat dan Protein** — Sama seperti Daily Calories fiturnya, namun yang membedakan adalah sesuai dengan gizi nya masing-masing, Untuk Daily Targetnya bisa di customize by user input.
5.  **Daily Body Weight** — User memasukan Body Weight harian.
6. **Summary by Custom Date** — User dapat melihat seluruh nilai gizi yang telah dimasukan dan di totalkan sesuai range tanggal yang dipilih, Start dan End Date.
7. **Day and Date** — User dapat melihat tanggal dan hari kapan dia Logging Makanan nya, bisa di tanggal berapapun di masukan, baik back date sekalipun, 

Bentuk: **PWA** mobile-first, di-hosting gratis.
